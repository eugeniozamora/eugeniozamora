# Eugenio Zamora — Fractional CTO / Full-Stack Technical Consultant

I design and ship production systems for founders and small teams who need senior engineering judgment without a full-time hire: multi-tenant SaaS platforms, AI-powered backends, and cross-platform mobile apps — from architecture decisions through to what's actually running in production.

- **AI-powered backends** — multi-agent systems, privacy-first architecture, LLM integration (Anthropic Claude)
- **Multi-tenant SaaS** — tenant isolation, auth architecture, B2B2C product design
- **Mobile apps** — Flutter, end-to-end from concept to store release
- **Legacy migrations** — replacing a live system's foundation without a rewrite-and-pray
